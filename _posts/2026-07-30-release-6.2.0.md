[Version 6.2.0](https://github.com/SasView/sasview/releases/tag/v6.2.0) was
released on Jul 30, 2026!

This is a feature release, which comes with a number of new features, improvements, and bug fixes as listed below.

This version of SasView is built with Python 3.13, Sasmodels v1.1.0, Sasdata v0.12.2, and Bumps v1.0.5.

**New Features**

* Multiple slicers are now supported, including plot stacking and symmetric slicers.
* The Invariant perspective has been given a major facelift, with a more user-friendly navigation. It now supports the calculation of SLD contrast from volume fraction (reverse calculation) and uncertainties on input parameters.
* A new button is now available for any 1D plot to be sent to the Data Explorer for further analysis.
* Support for SAXS fitting v2 has been added.
